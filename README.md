# rock_paper_scissors

User inputs 1, 2 or 3 (rock, paper or scissors).
Input is turned into the relevant word and then output back to the user.
Script randomises 1, 2 or 3 and outputs to user as relevant word.
Logic:
Rock > Scissors
Paper > Rock
Scissors > Paper
IF user input > script output THEN user win ELSE IF user input < script output THEN script win ELSE draw
